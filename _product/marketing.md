2. **Judging weights (Official Rules): Impact 30%, Use of Meta AI Tooling 25%, Demo 25%, Technical Depth & Execution 20%**, each scored 0–10 after a pass/fail gate (fits a theme, really uses Meta models). The top 5 per track go to a live final where judges watch the videos.

4. **Video rule: a 3-minute demo video showing only what was built during the event.** "Failure to clearly identify your original contributions will result in immediate disqualification." The video is a primary judging artifact, with the code and the live product.
5. **Repo rule: the repository must be public**; check it in a logged-out browser before submitting. `hadrienbaradel/scam-shield` is private as of Oct 27.
